**MADR** (Markdown Any Decision Records, originally Markdown Architectural Decision Records) is a lightweight template for recording decisions as Markdown files in the repository. Each record captures the context, the options considered, the decision, and its consequences. We record significant architecture and technology decisions as MADRs, so the reasoning is reviewed in pull requests, versioned with the code it affects, and easy to find when someone later asks why.
