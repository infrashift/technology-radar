**Terraform** is how we provision infrastructure in Google Cloud and our datacenter. Declarative configuration, a reviewable plan before every change, and providers for nearly every API mean infrastructure changes go through the same pull request flow as code. HashiCorp moved Terraform to the Business Source License in 2023; OpenTofu, the open-source fork, remains a compatible alternative if the licensing ever becomes a problem for us.
