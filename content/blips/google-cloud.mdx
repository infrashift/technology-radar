**Google Cloud** is our public cloud. We use it for workloads that need elastic capacity, global reach, or managed services we don't want to run ourselves, while steady-state workloads run in our private datacenter. We manage it with Terraform like everything else and favor open interfaces over proprietary services where portability matters.
