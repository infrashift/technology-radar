**Neovim** is our recommended editor. It runs in the terminal, so it works the same in a remote workspace over SSH as it does locally; it has built-in LSP support for language-aware editing; and it's configured in Lua, so a team configuration can be versioned and shared. It's fast and light on resources. The learning curve is real, and we invest in shared configuration and pairing to flatten it.
