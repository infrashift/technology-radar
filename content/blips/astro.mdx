**Astro** is our framework for static sites: project documentation, websites, and this Technology Radar. It renders pages to static HTML at build time and ships no JavaScript unless a component needs it, adding interactive islands only where they're useful. Content lives in Markdown and MDX with typed content collections, and the output can be hosted anywhere that serves static files. Astro is now backed by Cloudflare and remains MIT-licensed open source.
