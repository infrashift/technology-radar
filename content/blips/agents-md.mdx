**AGENTS.md** is a common format for providing instructions to AI coding agents working on a project. Essentially a README file for agents, it has no required fields or formatting other than Markdown, making it easy for teams to adopt incrementally. We see growing convergence across AI tool vendors in recognizing this convention.
