**htmx** lets us build interactive web interfaces by returning HTML from the server and declaring behavior with HTML attributes such as `hx-get`, `hx-post`, `hx-target`, and `hx-swap`, rather than building a single-page application. There's no client-side build, state stays on the server, and a Go service using `html/template` and htmx covers most of our web needs with a fraction of the code. When we build a web interface rather than a TUI, htmx is our default.
