**htmx** allows you to access modern browser features directly from HTML using attributes, without writing JavaScript. It supports AJAX requests, WebSockets, and server-sent events through declarative HTML attributes. Teams are assessing htmx for content-heavy applications where a full SPA framework feels excessive.
