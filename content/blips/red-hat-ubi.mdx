**Red Hat Universal Base Images (UBI)** are our standard base for OCI container images. They're built from RHEL content, receive Red Hat's security updates, and can be freely redistributed, so the images we publish don't need a subscription to run. The minimal and micro variants keep images small, and using the same package base in containers and on hosts means one set of security advisories to track.
